# Contributing to FluxionX

All contributions are welcome! Code, documentation, graphics, or design suggestions.

## Adding language files

1. Copy the English language files from:
   - `./attacks/Handshake Snooper/language/en.sh`
   - `./attacks/Captive Portal/language/en.sh`
   - `./language/en.sh`
2. Translate the strings
3. Save them as `LANGUAGE_CODE.sh` to the respective locations.

Resource: [ISO 639-1 codes](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes)

## Pull requests

Please submit pull requests to the `main` branch. Follow the existing code style and conventions.
